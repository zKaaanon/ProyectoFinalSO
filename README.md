## Descripción
Este repositorio fue creado con el motivo de la entrega del proyecto final de la materia **Sistemas Operativos 2026-2**.  

---

## Detalles del Proyecto
1. **Modificación de código de un SO Open Source**  
   - Seleccionar un sistema operativo de código abierto (puede ser un componente como CVS, Linux Kernel, FreeBSD, etc.).  

2. **Identificación y solución de un bug documentado**  
   - Consultar issues o foros oficiales.  

3. **Documentación técnica del proceso**  
   - Detección, análisis, corrección y pruebas.  

4. **Referencias y pruebas**  
   - Incluir referencias al bug original y pruebas que demuestren la corrección.  

---

## Entregables
- **Trabajo escrito (PDF):**  
  Introducción, objetivos, marco teórico, desarrollo, resultados y conclusiones.  

- **Repositorio en GitHub:**  
  Código fuente, guía de uso/instalación y un video de funcionamiento del sistema.  

- **Exposición:**  
  10-15 minutos mostrando resultados, problemas encontrados y funcionamiento.
